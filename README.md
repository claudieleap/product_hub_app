# Product Hub App

Frontend do **Product Hub** Aleevia — Vue 3, Vite, PrimeVue e Tailwind.

## Stack

- Vue 3 + Vue Router
- Vite 8
- PrimeVue 4 + PrimeIcons
- Tailwind CSS 4
- Axios

## Desenvolvimento

```bash
npm install
npm run dev
```

App em `http://localhost:5173`. O proxy do Vite encaminha `/api` para `http://localhost:8000` (product_hub_api).

## Variáveis

Copie `.env.example` para `.env` se precisar apontar para outra URL de API.

## Build

```bash
npm run build
npm run preview
```
